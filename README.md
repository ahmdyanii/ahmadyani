# Portofolio Ahmad Yani

Website portofolio pribadi yang dibuat sebagai tugas mata kuliah
Pemrograman Web menggunakan HTML dan CSS.

## Tentang Project

Website ini menampilkan informasi mengenai profil, kemampuan,
project, galeri, dan kontak.

Website dirancang dengan tampilan modern dan responsive serta
menerapkan materi dari Modul 3, Modul 4, Modul 5, dan Modul 6
Pemrograman Web.

## Project yang Ditampilkan

### 1. Aplikasi Manajemen Barang

Aplikasi berbasis web untuk membantu pengelolaan data barang,
stok, status, pencarian, serta pembuatan laporan dalam format
PDF dan Excel.

### 2. Dashboard Analisis Kasus & Barang Bukti

Dashboard interaktif berbasis web untuk menganalisis data kasus
dan barang bukti dari file Excel dengan fitur filter, statistik,
visualisasi data, dan pencarian.

### 3. Laundry Management System

Aplikasi berbasis web untuk membantu pengelolaan layanan laundry,
data pelanggan, pesanan, pembayaran, pengantaran, kurir,
dan komplain melalui dashboard admin.
